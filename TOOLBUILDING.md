# syednazli1025.github.io
**Building a Python Port Scanner!**

• Developed a Python-based TCP port scanner using the `socket` library to automatically test ports 1–1024 on a specified target IP address.
• Implemented connection timeouts and socket handling to efficiently determine whether individual ports were open or closed.
• Added functionality to identify common service names associated with discovered open ports.
• Implemented banner grabbing to retrieve information returned by accessible network services for additional enumeration.
• Tested and validated the tool against a Windows virtual machine in an isolated VMware cybersecurity lab, comparing results with Nmap.
